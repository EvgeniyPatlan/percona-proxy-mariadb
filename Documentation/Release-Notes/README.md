# Release Notes

`Percona-Proxy-1.0.0-Release-Notes.md` describes this product.

The `MaxScale-23.08.*` documents are the release notes of MariaDB MaxScale, the product this
one is derived from. They are kept because Percona Proxy for MariaDB 1.0.0 corresponds to
MaxScale 23.08.12, so they describe how the code reached that state. They deliberately keep
the upstream name: those releases were made by MariaDB, not by Percona.
